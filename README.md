A one-image newspaper front page summing up the world news of Thursday, 19 November 2026: the first-ever trilateral summit of Donald Trump, Xi Jinping and Vladimir Putin in Shenzhen, Ukraine's European allies gathering in Berlin, supertankers ablaze in the Strait of Hormuz, and Trump's promised meeting with Kim Jong-un. The whole page is drawn in code — a pure Python standard-library program renders the masthead, headlines, body text and every illustration itself into a deterministic 1024x1024 PNG, with no network access and byte-identical output on every run.

## Run it

```sh
mkdir -p out && python3 main.py out/entry.png
```

With no argument the program writes `/output/entry.png` instead.
